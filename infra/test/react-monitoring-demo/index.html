Демо-сервис счетчика просмотров

При каждом открытии этой страницы конкретная реплика сервиса увеличивает свой локальный счетчик.

Реплика / hostname
__HOSTNAME__
Порт приложения
__PORT__
Локальные просмотры
__COUNT__
Время ответа
__TIME__

Полезные endpoints: /api/stats, /metrics, /health

Если при обновлении страницы меняется hostname, значит запрос попал в другую реплику.
